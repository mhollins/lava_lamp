# Lava Room

A responsive Next.js lava lamp with animated merging wax, six color palettes, adjustable flow speed, pause/resume, and full screen. Respects the system’s reduced-motion setting.

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000.

## Check and build

```sh
npm run typecheck
npm run build
```

The simulation uses SVG filters and CSS animation. No API keys or backend services are required. Fonts use Google Fonts, with local system fallbacks.
